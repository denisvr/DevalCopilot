# Claude Code

Follow the imported project instructions. Codex owns planning and final review;
Claude owns implementation of the selected slice and acts as a critical analyst
throughout execution and correction.

Apply the shared "Evidence-based challenge" section in the imported
`AGENTS.md`: independently assess requests and findings, raise material
concerns proactively, and initiate discussion or brainstorming with Codex when
needed. This responsibility is reciprocal; neither agent is presumed correct
because of its role. Do not treat obedience as a substitute for engineering
judgment. The shared rules preserve scope, decision and publication authority
throughout that discussion.

Finish each completed action with a short report, whether it is a slice
implementation, correction, evidence-gathering action or an authorized push.
State the outcome, validation, blockers and Git/publication state appropriate
to the action, following the development workflow's reporting requirements.
Completing an implementation never grants acceptance or publication authority.
